# Power BI Portfolio

A collection of Power BI reports supported by Excel-based data preparation and analysis. Each project folder contains its report file, preview images and project notes.

![Power BI portfolio preview](PBI.jpg)

## Projects

### 1. Fruit and Vegetable Sales Analysis
**Tools:** Excel, Power BI  
Explores sales performance across countries, products and time periods. The project includes Excel data preparation and dashboards, alongside a Power BI report with sales trends, country comparisons, product breakdowns and summary KPIs.

- [Project notes](SalesProject/Readme.md)
- Power BI file: `SalesProject/Fruit Sales Performance.pbix`

### 2. Life Expectancy, Health Expenditure and GDP Analysis
**Tools:** Excel, Power BI  
Compares life expectancy, health expenditure and GDP indicators across continents. The report uses regional aggregation to make broad patterns and differences easier to explore.

- [Project notes](LifeExpectancy/Readme.md)
- Power BI file: `LifeExpectancy/Global Health Report.pbix`

### 3. Udemy Courses Performance Report
**Tools:** Power BI  
Explores course subscribers, reviews, pricing, course duration, lecture counts, ratings and category-level patterns.

- [Project notes](Udemy/README.md)
- Power BI file: `Udemy/Personal Project .pbix`

## Viewing the reports

Download a `.pbix` file and open it with [Power BI Desktop](https://www.microsoft.com/power-platform/products/power-bi/desktop). Preview images are provided for quick review, but the PBIX files are required to explore report interactions.
