# Udemy Courses Performance Report

## Overview

This Power BI report explores a dataset of Udemy courses, with attention to subscriber activity, pricing, course content and learner engagement.

## Analysis areas

- Subscriber trends over time
- Paid and free course pricing/revenue measures
- Course duration and lecture counts
- Reviews and ratings
- Comparisons across course categories and course levels

## Dataset fields

The available dataset includes course ID, title, URL, price, subscribers, reviews, lecture count, course level, content duration and publication timestamp.

## Files

- `Personal Project .pbix` — interactive Power BI report
- `udemy_courses - udemy_courses.csv` — dataset
- `Key_Metrics.png`, `Subscriber_Pricing_Metrics.png`, `Trend_Analysis.png` — report previews
